# Only required on the deployment machine (Raspberry Pi) for --mode vad.
# Push-to-talk (--mode voice), text (--mode text), and --simulate work without it.
# webrtcvad-wheels
#
# webrtcvad-wheels is the maintained fork of webrtcvad: same `import
# webrtcvad`, prebuilt aarch64/Python 3.12 wheels (no C compiler needed).
# Use it instead of the original `webrtcvad` package (abandoned since 2020),
# which does a module-level `import pkg_resources` - removed from setuptools
# (confirmed gone by 80.10.2), so it only imported with setuptools<81
# pinned. The fork reads its version via importlib.metadata instead
# (checked in 2.0.14's source), so no setuptools pin is needed. Switched on
# the Pi 2026-09-30 and confirmed working in --mode vad. Uninstall
# `webrtcvad` before installing this - both ship the same module files.
#
# Also for --mode vad: wake-word detection. NOT a plain `pip install
# openwakeword` — see cozmo_brain/audio/wakeword.py for the exact install
# command (it has a broken dependency on Python 3.12/Linux otherwise).

# Only required if STT_PROVIDER or TTS_PROVIDER=local in .env — fully
# offline STT/TTS, no API key, no rate limits. See cozmo_brain/llm/local_client.py.
# faster-whisper (CTranslate2 Whisper reimplementation, real CPU speedups) for STT:
# faster-whisper
#
# Piper (fast local neural TTS, validated for Raspberry Pi-class hardware)
# for TTS. NOTE: the currently maintained `piper-tts` package (published
# from the OHF-Voice/piper1-gpl fork, since the original rhasspy/piper repo
# was archived) is GPL-3.0-or-later, not the original's MIT license — worth
# confirming that's acceptable for this project before installing.
# piper-tts
#
# Piper also needs a voice model downloaded once (creates <name>.onnx +
# <name>.onnx.json in the current directory) before LOCAL_TTS_VOICE_PATH in
# .env can point at it:
# python3 -m piper.download_voices en_US-lessac-medium

# Only required if TTS_PROVIDER=edge in .env — Microsoft Edge's online TTS
# via the unofficial edge-tts library: free, no API key, needs internet.
# TTS only, no STT counterpart. See cozmo_brain/llm/edge_client.py.
# edge-tts
#
# edge-tts's service only ever returns MP3 (confirmed against its source,
# not configurable) — av (PyAV) decodes it to WAV before it reaches
# tts_postprocess.py, which is built on Python's stdlib `wave` module and
# can't read MP3 directly. Ships FFmpeg bundled in its own wheel (no
# system ffmpeg install needed), and is already a dependency of
# faster-whisper (STT_PROVIDER=local) — often already installed for free
# if that's in use too.
# av
